1. MOTIVO Y DIAGNÓSTICO INICIAL DEL PROBLEMA
--------------------------------------------------------------------------------
* Situación inicial:
  - Python 3.12 y YT-TUI estaban instalados en Windows 10.
  - La interfaz de YT-TUI abría correctamente, pero no reproducía vídeos ni audio.
  - Al ejecutar "mpv --version" en consola, parecía no mostrar salida.
  
* Diagnóstico técnico:
  1. `mpv.exe` en Windows es un binario compilado como aplicación gráfica (GUI), por
     lo que no redirige su salida al stdout/stderr de la consola a menos que se use
     `mpv.com`.
  2. YT-TUI buscaba ejecutables `mpv` únicamente en el PATH o en subdirectorios
     predecibles de Scoop / WinGet / `C:\Program Files\mpv`, pero en este equipo estaba
     instalado en `C:\Program Files\MPV Player`.
  3. Textual llamaba a `self.app.suspend()` antes de abrir el reproductor en segundo
     plano. En Windows, suspender la aplicación de consola causa artefactos gráficos
     o congelamiento de la ventana.
  4. Las miniaturas en consola se renderizaban a baja resolución y el panel de vista
     previa era muy estrecho para apreciar los vídeos.

2. ARCHIVOS MODIFICADOS Y DETALLE EXACTO DE CAMBIOS
--------------------------------------------------------------------------------

[A] yt_tui/player.py
--------------------
  * Detección mejorada de MPV en Windows (función find_tool):
    - Se agregaron las rutas típicas de Windows:
        C:\Program Files\MPV Player
        C:\Program Files (x86)\MPV Player
    - Se agregó soporte para resolver tanto ".com" como ".exe" (mpv.com / mpv.exe).
  * Título dinámico en la ventana del reproductor:
    - Se añadió el argumento `title: str | None = None` a `play()` y `play_async()`.
    - Se inyecta la bandera `--title={title}` al comando de MPV para que la ventana
      muestre el nombre real del vídeo en lugar de una URL cruda.
  * Modo solo audio mejorado:
    - Cuando se reproduce en modo audio, se añadieron las opciones:
        --force-window=immediate
        --autofit=520x260
      Esto abre una pequeña ventana gráfica responsiva que permite pausar, adelantar
      y controlar el volumen con atajos de teclado sin perder el control de la consola.

[B] yt_tui/thumbnail.py
-----------------------
  * Mayor resolución de imagen:
    - Ancho por defecto `WIDTH_DEF` aumentado de 38 a 62 columnas.
  * Renderizado gráfico avanzado con Chafa (función _run_chafa_sync):
    - Parámetro `--symbols vhalf+quad+sextant`: utiliza bloques medios y sextantes
      para duplicar la densidad de píxeles en caracteres Unicode.
    - Parámetro `--color-space din99d`: cálculo perceptual de colores para mayor
      fidelidad.
    - Parámetro `--work 9`: nivel máximo de trabajo/muestreo de Chafa.
    - Parámetros `encoding="utf-8"` y `errors="replace"` en el subprocess para evitar
      errores de decodificación en Windows con caracteres extraños.
  * Tolerancia a fallos (Fallback):
    - Si el comando avanzado de Chafa falla o la terminal no soporta los caracteres,
      reintenta automáticamente con el conjunto básico de símbolos.
  * Sanitización ANSI:
    - Protección contra cadenas vacías o `None` en `_clean_ansi()`.

[C] yt_tui/ui.py
----------------
  * Rediseño y ampliación visual (CSS):
    - `#info-panel`: Ancho ampliado de 44 a 66 columnas (padding `0 1`).
    - `#thumb`: Altura ampliada de 12 a 19 filas (marco con borde estilizado).
  * Conexión con alta resolución:
    - `_fetch_thumb` ahora invoca `thumbnail.render(url, width=62)`.
  * Corrección de freeze en Windows:
    - Se añadió `if sys.platform != "win32"`: en Windows se omite `self.app.suspend()`,
      evitando que la terminal quede en negro o se trabe al abrir MPV.
    - Se pasa el título del vídeo (`item.get("title")`) a las llamadas de reproducción.
  * Nuevo atajo para ver miniaturas en HD nativo:
    - Se agregó el atajo de tecla [T] ("Thumb HD") en `BINDINGS`.
    - Se implementó `action_open_thumb()`: localiza el archivo JPEG descargado en la
      carpeta de caché (`~/.cache/yt-tui/thumbnails/`) y lo abre inmediatamente con
      `os.startfile()` en el visor de fotos predeterminado de Windows en resolución original.

3. CONTENIDO DE LA CARPETA player_bin/ (REPRODUCTOR MPV PORTABLE)
--------------------------------------------------------------------------------
Esta subcarpeta contiene una copia completa de MPV Player:
  - `mpv.exe` (Binario principal de 64 bits)
  - `mpv.com` (Wrapper para uso y logs en línea de comandos)
  - `d3dcompiler_43.dll` (Librería DirectX necesaria para aceleración por hardware)
  - `installer/` (Scripts para asociar MPV a nivel de sistema si se desea)
  - `doc/` (Manual oficial y hoja de atajos de teclado)

--------------------------------------------------------------------------------
4. CÓMO VOLVER A INSTALAR / EJECUTAR ESTE CÓDIGO
--------------------------------------------------------------------------------
Si deseas trabajar en este código o instalarlo en otro entorno con Python:

1. Abrir terminal en la carpeta del proyecto:
   cd C:\Users\Administrator\Desktop\yt-tui-backup

2. Instalar en modo editable con pip o uv:
   pip install -e .
   (o con uv: uv pip install -e .)

3. Ejecutar:
   yt-tui

4. Atajos principales dentro de YT-TUI:
   - [/] : Buscar vídeos
   - [Enter] : Reproducir vídeo con MPV
   - [T] : Abrir miniatura en HD en visor de Windows
   - [A] : Alternar reproducción automática (Autoplay)
   - [H] : Ver historial
   - [S] : Pestaña de búsqueda
   - [F1] : Ayuda y lista de comandos
   - [Ctrl+Q] : Salir de YT-TUI
